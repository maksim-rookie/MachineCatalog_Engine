# Изменения 8.4.5

Новое название проекта: **MachineCatalog Engine 8.4.5**. Версия создана на базе PDF_SEARCH 8.4.4.

## P0

- Многоязычные маркеры таблиц и китайские названия строк подключены через JSON.
- Таблицы без вертикальных линий получают столбцы из координат заголовков и подтверждающей геометрии. Пустоты сохраняются; неоднозначные значения не распределяются между моделями.
- Класс и тип определяются локально для таблицы/модели. Обязательные поля в контроле качества выбираются по классу модели, а не документа. Добавлена проверка смешанных каталогов и соседних таблиц разных классов.
- Полные дефисные обозначения, составные суффиксы и китайские квалификаторы модели сохраняются. Старые правила вариантов интерфейса и поколений проходят регрессионные проверки.

## P1

- `config/dictionaries/en.json`, `zh.json`, `ru.json`: маркеры, типы станков, опциональность и дополнительные правила характеристик. Содержимое словарей включено в аудит схемы и подпись кэша.
- Опциональные разделы не заполняют штатные значения и обязательные поля. Опции экспортируются отдельно.
- Диапазоны экспортируются с границами; составные значения остаются нечисловыми. Обратные диапазоны, отрицательные физические значения, неоднозначные скобки и несовместимые/неизвестные единицы блокируют числовой импорт.
- Добавлен коэффициент пересчёта единиц в типизированном экспорте: исходные тонны сохраняются в raw, числовая масса экспортируется в килограммах.
- Линейная и угловая точность разделены условиями `axes=X/Y/Z`, `axes=A/C` и т.п.

## Поставка

- Отдельные каталоги вывода и кэша `v8_4_5`.
- Добавлены PDF Kaibo, 190 исходных контрольных ячеек и регрессионные тесты новой функциональности.
- Исторические результаты и документация 8.4.4 не переименовываются в новые результаты. Исходная версия сохранена отдельным резервным архивом в облачной среде.
