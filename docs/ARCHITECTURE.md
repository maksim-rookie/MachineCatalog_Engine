# MachineCatalog Engine 8.4.5 — архитектура

`main.py → runner.py → extract.py → geometry.py + identity.py + models.py + schema.py + values.py → quality.py → exports.py`

- `geometry.py`: физические ячейки с объединениями; дополнительное восстановление столбцов по заголовкам и координатам строк при отсутствии вертикальных линий. Координатная неоднозначность оставляется для аудита, соседние значения не копируются.
- `identity.py`: локальные заголовки и параметры конкретной таблицы определяют класс/тип; заголовок конкретной модели может уточнить тип. Документ получает сводный класс только после классификации моделей.
- `models.py`: разбор полного буквенно-цифрового обозначения, дефисных суффиксов, вариантов интерфейса и поколения; исходный заголовок сохраняется.
- `schema.py`, `config/schema.json`, `config/dictionaries/*.json`: многоязычные правила и разделы, пользовательские overrides. Полное содержимое словарей участвует в подписи кэша.
- `values.py`: исходные значения, условия, опции, размерности и проверка диапазонов; перевод единиц ограничен явно поддерживаемыми совместимыми единицами.
- `quality.py`: обязательные поля отдельно по классу каждой модели; опциональные поля не считаются штатными. Завершение обработки, полнота извлечения и качество — отдельные результаты.
- `exports.py`: исходные факты и геометрия, просмотровые таблицы, опциональное оснащение, числовой слой с коэффициентом пересчёта и границами диапазонов.
- `runner.py`, `storage.py`, `progress.py`: изолированные запуски, кэш по содержимому входа/движка/схемы/словарей, история и хронометраж.

Значения моделей, страницы и хэши конкретных каталогов не используются как профили движка. Контрольные данные находятся только в тестах и benchmarks.
