# MachineCatalog Engine 8.4.5.1

- Одинаковые параметры разных языков используют одну каноническую категорию и один столбец; устранены дубли `Capacity/Travel` и `Machine/Machine dimensions`.
- Все конфигурации представлены в строке модели, включая модели без `base`. Небазовые значения и неприменимость подписаны; отдельный CSV конфигураций сохранён.
- Масса в тоннах и мощность в ваттах отображаются в единицах целевого параметра. Источник остаётся в long и подсказке широкого CSV. Угловая и линейная точность различимы по единицам.
- Явно подписанные векторы X/Y/Z, поворотных осей и встроенные единицы электропитания получают отдельные компоненты с `parent_fact_id`; исходные факты сохранены. Неоднозначные значения не раскладываются.
- Производитель Kaibo определяется по явному тексту компании в PDF.
- Снят прежний список скрытых столбцов по умолчанию. Добавлен аудит каждого факта в широкой таблице с проверкой присутствия значения.
- Входные PDF, результаты и кэш перенесены во внешний корень данных; CLI поддерживает `--data-dir`, `--init-data`, `MACHINECATALOG_DATA_DIR`. Старые данные сохранены с проверкой контрольных сумм.
- Добавлен безопасный повторный экспорт сохранённого запуска без утверждения, что исходные PDF распознаны заново.
