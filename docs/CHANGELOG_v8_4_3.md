# PDF_SEARCH 8.4.3 - изменения

Новый основной движок: 8.4.3-geometry-1.

- Векторная геометрия ячеек и резервный разбор таблиц по линиям/тексту.
- Отдельные модели, поколения, конфигурации и условия значений.
- Токарные параметры, противошпиндель, задняя бабка и револьверная головка.
- Управляемая через JSON схема без значений конкретных станков.
- Первичные источники, координаты, неизвестные поля и диагностика вместо догадок.
- Разные признаки выполнения, полноты извлечения и качества данных.
- Отдельный кэш cache_v8_4_3, его инвалидация по коду и шеме, запуск --no-cache.
- Сохранены проценты, время и история запусков.
- Новый ALL_CONFIGURATIONS_wide.csv; полные источники в ALL_MODELS_long.csv.
- Совместимость со старым кодом изолирована в compat_v842.py и не вмешивается в новый путь без явного режима.

Не заявляется полное покрытие произвольных каталогов. Границы, проверенные документы и замечания смотрите в README_RU.md и отчете VALIDATION_REPORT.md.
