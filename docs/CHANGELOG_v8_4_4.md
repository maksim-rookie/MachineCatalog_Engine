# CHANGELOG — PDF_SEARCH 8.4.4

- Сохранены извлечение таблиц по векторным линиям/координатам, fallback pdfplumber,
  объединённые ячейки, прогресс, таймеры и история запусков.
- Исправлено распознавание числового суффикса после буквенного: `DVF 8000T/50`.
- Исправлено разрешение подполей по последнему обозначению строки (`Pull stud`).
- В `config/schema.json` добавлены `section_unit_rules`, синоним `Contrel`,
  дополнительные описания диаметра инструмента, Tool to Tool, Coolant tank,
  coolant pump motor power.
- Для `Tool storage capacity` в разделе Table с единицей kg применяется
  `table_load_kg`, обязательно с предупреждением об исходной неоднозначности.
- Добавлен ограниченный recovery отсутствующей нижней строки таблицы по
  координатам слов (`geometric_tail_row_recovered`, требует проверки).
- Масса DVF 5000, зависящая от 30/40/60/120 инструментов, хранится с условиями.
- `MEASUREMENTS_TYPED.csv`: числа только для одиночных метрических значений;
  сомнительные факты не получают числового значения для прямого импорта.
- Введён контроль возможных коллизий идентификаторов модели из разных колонок.
- Отдельные выходные каталоги и кэш v8_4_4, версия fingerprint, обновлены BAT.
- Сохранены механизмы Lynx [] / DHF ** и существующие регрессионные тесты.
- 98 автоматических тестов; проверка на четырёх исходных PDF и offline replay
  девяти таблиц из восьми PDF предыдущего запуска.
