# Архитектура 8.4.5.1

`main.py → paths.py / runner.py → extract.py → normalization.py → quality.py → exports.py`

`geometry.py`, `identity.py`, `models.py`, `schema.py`, `values.py` выполняют геометрический и семантический разбор. `normalization.py` оставляет исходные факты и добавляет только однозначно подписанные компоненты. Все правила сопоставления, категории и правила разложения заданы в JSON-схеме.

Идентификатор столбца — каноническая категория и ключ параметра; язык источника не меняет столбец. Широкая строка модели включает все конфигурации с явными условиями. Отдельный аудит сверяет отображение каждого факта с реально сформированной ячейкой.

`paths.py` размещает данные вне checkout. `tools/reexport_run.py` повторно строит представления из сохранённых фактов, сохраняя признак отсутствия нового PDF-прохода. Исходные источники, результаты и архивы не входят в исходную поставку.
