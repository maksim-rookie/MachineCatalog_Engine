# Разбор неполных таблиц и исправления 4.8.5.4

Исходные данные: `run_20261102_115930_137834.7z` и последний исправленный проект 4.8.5.3. Пересобранный запуск: `run_20261102_122644_348279`.

## Причины

1. Нормализатор принимал преимущественно скаляры и не сохранял отображение текста, диапазонов, сложных значений и прочерков. В прежнем нормализованном выводе были пусты 1 164 из 3 811 записей.
2. Общий список производных столбцов применялся ко всем моделям; отсутствие производного значения могло затереть уже заполненную ячейку отдельной оси. Восстановлено 156 ячеек прежней широкой таблицы.
3. Словари использовали разные ожидаемые единицы одного ключа: `rpm/r/min`, `N*m/N.m`, `pcs/ea`. `mm/min` ошибочно попадал в семейство длины, а не скорости.
4. Нормализация не сохраняла условия и опции в достаточной мере для общей таблицы. Также встречаются PDF-символы U+F688/U+F689 вместо скобок.
5. Подпись `Recommanded turning dia.` не распознавалась. Три физических ячейки дают шесть назначений моделям, уже установленных геометрическим парсером.
6. Одна ячейка NC system была ошибочно отмечена потерянной: восстановленная общая область отличалась от исходного физического прямоугольника. В фактах теперь сохраняется и исходный прямоугольник.
7. Экспорт и нормализация находились в одном крупном модуле; CSV мог остаться частично записанным при ошибке, а подробного журнала и извлечённых данных до экспорта не хватало для восстановления.

## Различия и нормализация

Полный перечень обнаруженных вариантов находится в `NORMALIZATION_AUDIT.csv` и `NORMALIZATION_VARIANTS.csv` пересобранного запуска: 83 канонических групп с различиями. Список содержит все наблюдённые варианты подписей, исходных ключей, единиц и форматов с ID фактов.

| Представление источника | Каноническое представление |
|---|---|
| `30/30/18 m/min` и отдельные X/Y/Z | Общие столбцы rapid_traverse_x/y/z_m_min |
| `45 (1771.7) m/min (ipm)` | `45`, единица `m/min`; исходная строка рядом |
| `1 ~ 6000 mm/min` | `0.001 ~ 6 m/min`; границы диапазона сохранены |
| B/C 最高转速 и Rapid traverse B/C | rotary_axis_speed_b/c_rpm |
| rpm / r/min | rpm |
| N*m / N.m / N·m | N·m |
| ea / pcs | pcs |
| t / kg | kg с явным коэффициентом |
| NC system / CNC system / 控制系统 | control_system с сохранением исходного текста |

Сомнительные физические единицы не исправляются предположениями. Они отображаются с исходной единицей и статусом. Условные значения и опциональное оборудование остаются обозначенными. Исходная строка, её единица, PDF SHA-256, файл, страница, строка, координаты и fact_id сохраняются рядом с нормализованным представлением.

## Проверенные результаты

- Все 3187 исходных фактов сохранили поля `value`, `value_raw`, `source_quote`, `source_page`, `source_file`, `cell_bbox`.
- Всего 3193 факта после шести восстановленных назначений; 95 строк модель/комплектация и 111 канонических столбцов.
- Все 2310 непустых физических ячеек обнаруженных таблиц покрыты фактами; потерянных непустых ячеек и нераспознанных строк — 0.
- Исходных фактов без экспорта — 0; заполненных исходных записей без отображения — 0; ошибок нормализации — 0.
- 48 тестов прошли; 14 интеграционных проверок PDF пропущены из-за отсутствия самих PDF. Лог проверок: `TEST_RESULTS_v4_8_5_4.txt`.

## Что остаётся проверить

В обнаруженных таблицах остаются 19 физических пустых ячеек (22 назначения моделям). Требования схемы по-прежнему отмечают 40 отсутствующих обязательных полей: 38 систем ЧПУ в KAIBO и ещё два поля. Из архива вывода нельзя доказать, что эти сведения присутствуют в других местах оригинальных PDF. Качество данных не объявлено полностью подтверждённым.

Точки развития: адаптеры геометрии для иных типов таблиц, структурный разбор сложных режимов работы/условий, проверка первичных PDF для спорных единиц и отсутствующих полей. Правила подписей и канонических единиц следует менять в конфигурации; физику преобразований — в `units.py`; синтаксис значений — в `canonical.py`.
